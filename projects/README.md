# Projects

Create a separate folder for each project. Copy [the project README template](../templates/project-readme.md) into that folder as `README.md`.

## Ideas

- Number guessing game: conditions, loops, and input validation
- Quiz app: functions, lists, and dictionaries
- Task manager: JSON storage and error handling
- Expense tracker: fictional transactions, CSV files, and summaries

These are suggestions, not completed projects. Start with one small working feature, then expand it.
