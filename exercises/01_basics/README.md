# Basics practice

Run `python3 exercises/01_basics/hello.py` from the repository root.

## Starter challenges

1. Change the name passed to `greet` and run the file again.
2. Read a name with `input()` and pass it to `greet`.
3. Create `temperature_converter.py`: convert Celsius to Fahrenheit using `celsius * 9 / 5 + 32`. Check that 0 becomes 32 and 100 becomes 212.
4. Create `even_or_odd.py`: read an integer and print whether it is even. Try 0, a negative number, and a positive number.
5. Create `sum_numbers.py`: calculate the sum from 1 through a positive integer. For 5, expect 15.

Mark your own progress in a daily log after completing each exercise.
