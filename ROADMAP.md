# Learning roadmap

Work at a comfortable pace. Check an item only after practicing it and explaining it in your own words.

## 1. Foundations

- [ ] Run a Python file from the terminal.
- [ ] Practice variables, numbers, strings, and booleans.
- [ ] Read input and format output.
- [ ] Use conditions and comparisons.
- [ ] Repeat tasks with `for` and `while` loops.

Suggested practice: a greeting program, a temperature converter, and an even/odd checker.

## 2. Collections and functions

- [ ] Work with lists, tuples, dictionaries, and sets.
- [ ] Define functions with parameters and return values.
- [ ] Split a program into small reusable functions.
- [ ] Use imports and standard library modules.

Suggested project: a quiz with a score and a list of questions.

## 3. Files and reliability

- [ ] Read and write text files with `with`.
- [ ] Save structured data using JSON or CSV.
- [ ] Handle expected errors with `try` and `except`.
- [ ] Validate input and investigate tracebacks.
- [ ] Write basic tests with `unittest`.

Suggested project: a command-line expense tracker using fictional sample data.

## 4. Program structure

- [ ] Understand classes, objects, and methods.
- [ ] Organize a small project into modules.
- [ ] Create a virtual environment before adding dependencies.
- [ ] Document setup, usage, and limitations.

Suggested project: a task manager that saves tasks between runs.

## 5. Choose a direction

- [ ] Try automation, data analysis, or web development.
- [ ] Choose a useful project with a small first version.
- [ ] Define success criteria and test them.
- [ ] Document what I learned and possible improvements.
